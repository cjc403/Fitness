## 推荐 1 ★★★ 会员体测与训练档案 + 变化曲线

**依据**：会员档案里**没有任何身体数据**。

**做什么**
- 记录：体重 / 体脂率 / 围度 / 静息心率 + 训练目标（减脂/增肌/体态/体能）
- **变化曲线**（手写 SVG，零依赖）：体重与体脂趋势、目标达成度
- **教练可代录**（私教课后顺手记），会员自己也能在会员中心补录
- **与私教课包关联**：上了 N 节课，指标变化多少 —— 这是"私教到底有没有效果"最直接的证据

**为什么最值得做**：私教场景刚需；**演示效果最好**（曲线一眼看懂）；
和已有的「预约 → 上课 → 评价」连起来，私教服务闭环就完整了。

**规模**：中（1 张表 + 迁移 V13 + 会员端/教练端页面 + SVG 曲线）

## 推荐 2 ★★★ 经营分析看板（含会员流失风险名单）

**依据**：报表偏资金核对，**没有经营视角**。

**做什么**
- **教练绩效排行**：课时数 / 私教产值 / 平均评分 / 续课率（评分上轮刚接通，正好用上）
- **会员消费与出勤明细**：可筛选、可导出
- **月度新增 / 留存 / 流失**
- **会员流失风险名单**：按「最近到店距今天数 + 预约频率下滑 + 权益即将到期」算风险分（**纯规则，不需要大模型**），
  高风险会员可直接派给会籍顾问跟进 —— 和刚做完的「顾问工作台」天然联动

**规模**：中

**依据**：会员**只能买本店商品**（`createSale` 强制同馆），权益按门店隔离。
