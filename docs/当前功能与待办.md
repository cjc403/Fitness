# FitChain 当前功能与待办（事实来源）

最后更新：2026-09-22。**判断项目现状一律以这份文档为准**；`后续完善计划.md` 已归档为历史规划。

## 技术栈与运行

- 后端 Spring Boot 3.3.13 + Java 17 + Flyway（V1–V10）+ QueryDSL；前端 Vue 3.4 + TypeScript + Vite 5 + Element Plus。
- 数据库：本地开发 H2；正式库 PostgreSQL 18（本地跑在 5433，服务器 5432）。**迁移 V1–V9 字节不可变，新需求走 V10+。**
- 本地启动：双击 `start.bat`；端口 后端 8080 / 管理端 9091（仅本机）/ 前端 5173。
- 版本控制：2026-09-22 起是 Git 仓库（此前没有版本控制）。

## 已上线能力（本地版本）

| 模块 | 能力 |
| --- | --- |
| 账号与权限 | 六角色 RBAC（超管/店长/教练/前台/会籍顾问/会员）；权限矩阵在 `security/RolePermissionCatalog`，登录写 JWT 并驱动 `@PreAuthorize`；强制改密、账号启停 |
| 会员 | 建档、门店归属、黑名单、会员自助中心（发现课程 / 我的预约 / 私教签课 / 购买会籍 / 我的会籍 / 消息 / 我的退款） |
| 课程与排课 | 课程 CRUD（超管可指定门店）、排课增删改、**教练必须绑定真实账号**、无教练的私教排课会醒目标记 |
| 预约与签到 | 预约 / 取消 / 请假 / 候补 / 签到 / 爽约；场馆锁 + 行锁防超员 |
| 会籍与商业 | 商品 CRUD + 删除（卖过的只能下架）、销售开卡、会员自助购买（`SELF_SERVICE` 渠道）、冻结/解冻/续费/转让 |
| 私教消课 | 预约预占 → 签到 → 教练提交 → 会员签课 → 正式扣次；提成规则与月结；**面板内自检 4 项前置条件** |
| 退款与价值账（V9） | 精确价值账、权益退款报价、申请/审核/拒绝/撤回/登记支付、**幂等键**、来源资金核对、退款项分摊 |
| 门禁 | 二维码入场核销、入场记录；**二维码为 60 秒一次性令牌**（V10） |
| 财务 | 对账报表、渠道分组、差异检测、CSV 导出 |
| 通知（V10） | 站内消息：排课变更、商品下架、退款审核/支付结果；会员端有未读角标 |
| 运维 | systemd 服务、备份/恢复脚本、健康检查、看门狗、nginx 配置、冒烟测试 |

## 数据库迁移

## 待办（按建议优先级）

| 优先级 | 事项 | 说明 |
| --- | --- | --- |
| P1 | 跨门店购买规则待定 | 会员目前只能买本店商品（`createSale` 要求同门店）；其他门店商品在会员端只展示。是否支持连锁通用需业务决策 |
| P1 | 滨江店没有教练账号 | 私教预约要求"教练账号门店 = 排课门店"，所以滨江店的私教排课无人可绑。需新建一个滨江店教练账号，或删掉无人可教的遗留排课 |
| P2 | 课程评价 | 有预约与出勤数据后可自然延伸 |
| P2 | 真实支付接入 | 现在所有支付都只是"登记"，`SELF_SERVICE` 渠道未接真实支付 |
| P2 | 门禁令牌清理任务 | `access_grant` 会持续增长，建议加个定时清理过期记录的任务 |
| P3 | i18n / 小程序 / APP / ELK / Prometheus 全家桶 | 现阶段收益低于成本 |

## 纪律（务必遵守）

1. **资金一律整数分**（`Money.cents`），金额取服务端值，前端不算退款/收款金额。
2. **不覆盖历史**：不做追溯扣课、不硬删有引用记录（订单/权益/预约/签课/退款）。
3. 生产验收只读；资金写只在隔离库或由用户自己点。
4. 迁移 V1–V9 字节不可变；`ddl-auto=validate` + `validate-on-migrate=true` + `clean-disabled=true`。
5. 未获明确授权不上线。
