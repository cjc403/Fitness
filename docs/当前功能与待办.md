## 技术栈与运行

- 后端 Spring Boot 3.5.16 + Java 17 + Flyway（**V1–V22**）；前端 Vue + TypeScript 5.9 + Vite 7 + Element Plus。未使用的 QueryDSL 已在此前加固中移除。
- 数据库：双击启动器实际使用 PostgreSQL 18（本地 5433，服务器 5432）；不带 prod 的开发配置可使用 H2。**已有迁移不可修改，新需求增加版本。**
- 时间：应用在 Spring/Hibernate 初始化前统一上海时区，避免回访/付款写入与跨月统计偏差；不改写历史时间。
- 本地启动：双击 `start.bat`；端口 后端 8080 / 管理端 9091（仅本机）/ 前端 5173。
- 版本控制：2026-09-22 起为 Git 仓库；组会断点标签 `checkpoint-2026-09-28`。

## 纪律（务必遵守）

1. **资金一律整数分**（`Money.cents`），金额取服务端值，前端不算退款/收款金额。
2. **不覆盖历史**：不做追溯扣课、不硬删有引用记录（订单/权益/预约/签课/退款）。
3. 生产验收只读；资金写只在隔离库或由用户自己点。
4. 已有迁移字节不可变；`ddl-auto=validate` + `validate-on-migrate=true` + `clean-disabled=true`。
5. 未获明确授权不上线。
6. **前后端加字段时，必须同步检查"手工拼请求体"的地方**——`roomId` 与"会员归属字段"都因此丢过数据。
7. **权限与角色的判定只允许一处**：`RolePermissionCatalog`（后端）+ `utils/accessControl.mjs`（前端，路由守卫与菜单共用）。
8. **在新鲜TEMP源码副本构建并验证**，不要clean或覆盖运行中的JAR；启用前备份库与旧JAR、核对项目PID并停旧后端，再复制已测试制品启动。
