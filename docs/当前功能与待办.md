## 技术栈与运行

- 后端 Spring Boot 3.3.13 + Java 17 + Flyway（**V1–V15**）+ QueryDSL；前端 Vue 3.4 + TypeScript + Vite 5 + Element Plus。
- 数据库：本地开发 H2（`fitness-backend/data/fitness.mv.db`）；正式库 PostgreSQL 18（本地 5433，服务器 5432）。**迁移 V1–V9 字节不可变，新需求走 V10+。**
- 本地启动：双击 `start.bat`；端口 后端 8080 / 管理端 9091（仅本机）/ 前端 5173。
- 版本控制：2026-09-22 起为 Git 仓库；组会断点标签 `checkpoint-2026-09-28`。

## 纪律（务必遵守）

1. **资金一律整数分**（`Money.cents`），金额取服务端值，前端不算退款/收款金额。
2. **不覆盖历史**：不做追溯扣课、不硬删有引用记录（订单/权益/预约/签课/退款）。
3. 生产验收只读；资金写只在隔离库或由用户自己点。
4. 迁移 V1–V9 字节不可变；`ddl-auto=validate` + `validate-on-migrate=true` + `clean-disabled=true`。
5. 未获明确授权不上线。
6. **前后端加字段时，必须同步检查"手工拼请求体"的地方**——`roomId` 与"会员归属字段"都因此丢过数据。
7. **权限与角色的判定只允许一处**：`RolePermissionCatalog`（后端）+ `utils/accessControl.mjs`（前端，路由守卫与菜单共用）。
8. **打包前先停本地后端（构建失败时不会产出 jar，应用会起不来）**：运行中的实例会锁住 jar，`clean` 会失败；更糟的是 `Copy-Item` 覆盖会原地截断，只能重启修复。
