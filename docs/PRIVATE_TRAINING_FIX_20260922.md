### ⚠️ 第 3 步「补绑滨江店那两条遗留排课的教练」**无法执行**，原因如下

私教预约在服务端要求 **教练账号的门店 = 排课门店**：

```java
// TrainingService.reserve
if (!Objects.equals(coach.getVenueId(), schedule.getVenueId())) throw failure("私教课程的教练账号不可用");
```

而库里**两个教练账号都在总部**（id=3 首席教练、id=8 陈教练），**滨江店没有任何教练账号**。
所以滨江店那两条私教排课（id=22 已有 3 条预约、id=23 无预约）**没有任何账号可绑**。

两种收尾方式，都需要你选择（本轮**未动**它们）：

1. **在「员工账号」里新建一个滨江店教练账号**（角色=教练、门店=滨江店），再去排课里绑定——之后滨江店也能跑私教。
2. **删掉 id=23**（无预约、9/26 00:00 那条），id=22 因有 3 条预约删不掉，保留为历史。

### P0 两端面板加"当前卡在哪一步"的引导

**会员端**（`TrainingPanel.vue` 的 `isMember` 分支，读本人课包 + 本门店私教排课）：

| 判断 | 展示 |
| --- | --- |

| 有课包且本门店有私教排课 | 成功提示"已就绪，可以去预约私教课了（N 节）" + **「去预约私教课」按钮** |

**管理端**（新增自检接口 `GET /api/v1/training/readiness`，鉴权 `COACH_WORKBENCH` 或 `MEMBERSHIP_READ`）：

返回 `{privateCourses, scheduledPrivateLessons, lessonsWithCoach, usablePackages}`，面板上按 4 条清单逐项打勾/叉，
未满足的直接写明该去哪里补：

1. 本门店有私教课程（当前 N 门）→ 去「课程与排课」新建课程类型为私教的课
2. 已排期的私教课（当前 N 节）→ 在「课程与排课」给私教课新增排课
3. 排课已绑定可用教练账号（当前 N 节）→ **私教排课必须绑定教练账号，只填姓名会员一约就报错**
4. 本门店有效的私教课包（当前 N 份）→ 会员没有课包无法预约私教

清单下另附一句"4 条都齐了但这里仍是 0 条，说明还没有会员预约私教课"。
