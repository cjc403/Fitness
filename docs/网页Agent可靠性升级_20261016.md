# 网页 Agent 可靠性升级（本地，2026-10-16）

本轮修复“打开课程与排课，把流瑜伽的价格改为99”却反复编辑其他课程的问题。升级作用于六角色共用的当前网页执行器，继续使用现有 DeepSeek 配置和业务接口。

## 原因与改动

| 已复现的原因 | 本轮修复 |
|---|---|
| 多张课程卡片都只向模型呈现“编辑课程”，缺少所属课程和门店 | 按钮附带卡片或表格行的业务对象、门店等上下文；同名不同门店分别保留 |
| 打开编辑弹窗后，背景课程仍可被操作 | 观察和执行限定最上层业务弹窗，以及与其输入框关联的浮层；旧背景引用立即失效 |
| 数字字段、单选项和范围输入的信息不足，长正文挤掉重要状态 | 优先提供实际字段值、只读/禁用/选中状态、组名及起止端点；目标对象优先进入有限快照 |
| 每步只反馈“已点击”，无法可靠核对当前编辑对象和修改结果 | 后续规划收到真实页面、弹窗、字段值和业务提交回执；对象或字段变化后的引用须重新观察 |
| 回执到达早于页面消费响应，已保存仍反馈旧编辑弹窗 | 等待响应处理、刷新读取和最终渲染后再核对，避免旧弹窗反馈诱发再次保存 |
| 错误动作反复重试，可能反复编辑、取消 | 按页面状态和动作对象检测无效重试及往返循环；先反馈恢复方向，再阻止重复操作并等待必要补充 |
| “改为99”“只把…改成…”可能被当成无需提交回执 | 补齐写操作判定；填写表单后仍须取得实际业务成功回执，才能报告完成 |

独立审查还发现并修复了真实 Element Plus 日期浮层的作用域、双月日历的控件预算和同标题门店反馈问题。日期单元格带完整年月日，双月日历中的目标日期、父表单起止输入及取消/保存共同保留在 60 控件预算内。时间范围输入已通过真实 Vue 受控值验证；焦点触发组件渲染期间暂停或停止会阻止后续填值。

## 验收结果

前端 **274/274** 项测试通过，TypeScript 检查及生产构建通过。保留原有主包体积提示。20 项新增回归覆盖真实 DOM、真实 Element Plus 日期/时间组件、对象变更、弹窗、预算、回执后的页面刷新、后态、循环及暂停停止保护。

真实模型使用本机受保护配置，浏览器写入只发生在带 `agent_browser` 标记的独占隔离库。前端工程标识、4177 的实际代理目标及数据库标记在登录前检查，浏览器流量限定在隔离前端。

| 真实场景 | 核对结果 |
|---|---|
| 原命令：把流瑜伽价格改为99 | 冻结请求指向正确课程编号，价格为99 |
| 已打开错误课程弹窗，再定位流瑜伽；另测价格和容量均实际改变 | 恢复到正确对象，两个字段达到目标，其他字段与其他课程不变 |
| 目标位于65张新增干扰卡片之后 | 目标进入有限观察范围，正确定位并修改 |
| 总部、店长、前台、教练、会籍顾问、会员的消息任务 | 六角色全部完成，后续规划收到实际确认回执，界面显示已完成 |
| 教练尝试改价 | 只读页面没有编辑入口；循环保护后进入等待补充，0次课程写入，全部课程不变 |

四条课程修改和六角色消息任务均核对：人工确认前 **0** 次实际提交、确认后 **1** 次、重复确认被拒绝、同一 Page 和 document。总部消息任务另测关闭助手及隐藏网页后的暂停与恢复，原确认仍保留。业务参数及未请求修改的数据也实际比对，不依据助手文字判断成功。

最终独立复审无重要发现，37/37 项专项测试通过，另用内存夹具核对最终渲染等待期间暂停与停止。证据入口：[verification.json](qa/agent-grounding-20261016/verification.json)；真实课程结果见 `final.json` 和 `multi.json`，六角色结果见 `six-role-final/model.json`，改动前的真实缺陷见 `probe-before-fix.json`。重复验收发现的“确认后仍准备再次保存”原始失败保留在 `final-before-render-settle.json`，对应修复和重验结果同时留档。日志保存在同目录，按仓库规则忽略。

## 使用与边界

当前浏览器请先按 **Ctrl+F5** 刷新，然后新建网页任务。可以输入原命令，观察当前页面的课程弹窗；需要提交时核对冻结参数，再确认这一次请求。开发时热更新可能保留旧任务实例，刷新后开始新任务可清除该状态。

本轮提升的是项目内的对象定位、执行反馈和恢复能力。已有验收覆盖上述场景，其他业务组合仍需逐项验收，不能据此承诺与其他 Agent 在所有任务上等价。权限负例目前会进入通用等待补充，后续可以进一步优化为具体的权限说明。

产品仍使用 DOM 和文字进行网页规划；本轮未接入网页截图视觉链。未修改 Java、JAR、执行器或已应用的23个迁移，未重新声称运行其旧测试。正常本地业务数据未用于试写，未更新服务器、未推送。共享交接文档的 §0.17 和 §10 同步维护，凭据章节原字节保留。
