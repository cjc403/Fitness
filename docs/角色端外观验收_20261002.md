## 接续开发方式

公共色彩、间距、圆角和状态样式维护在 `src/styles/polish.css` 的 `.wb-workspace` 范围。角色色彩通过根容器 `data-role` 和 `--wb-accent` 扩展。弹窗通过布局生命周期添加的 `body.wb-portal-active` 类应用主题。

`src/components/WorkspaceHero.vue` 提供 `heading`、`actions`、`footer` 插槽及 `compact` 属性。增加页面时沿用插槽，保留按钮事件与权限条件。装饰层禁止响应指针事件。

动效与比例规则位于 `src/utils/workspaceAppearance.mjs`；动效状态注入位于 `workspaceMotion.ts`。外观偏好键为 `fitchain.workspace.motion`，与登录凭据独立。

统计卡装饰和入场选择器必须排除 `.el-loading-mask`；教练旧样式中损坏的 media 查询已修正。风险/告警配色保留其业务含义。
