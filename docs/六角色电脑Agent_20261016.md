# 六角色当前网页 Agent（本地）

用户于 2026-10-16 明确修正需求：**在正在看的 FitChain 标签页操作**。旧版另开独立 Edge，即使那个窗口完成任务，当前经营看板也不会变化；该方式已从默认助手入口移除。

默认模型已统一为 DeepSeek-V4.1-Flash，官方 API 名称 `deepseek-flash`。模型的合成图片理解接口已独立验证；当前产品的观察输入仍为文字和DOM，没有自动发送页面截图，不能把默认模型切换表述为视觉Agent已经接入。

## 使用

1. 双击 start.bat，在原项目页面登录任一角色。
2. 打开右下角助手，在“会话”中使用默认的“网页执行”，直接描述目标。例如：“打开本网页的训练计划”。
3. 任务显示在“网页任务”。AI 直接点击当前页面菜单、填写表单、选择选项；当前地址及正文实际改变。操作目标有蓝色描边，不另开浏览器。
4. 可以暂停、继续、停止、补充信息。关闭助手或切到其他浏览器标签页会暂停；重新打开后手动继续。整页刷新会结束当前内存任务。
5. 保存、新建、发送等操作先冻结真实请求，展示实际字段。点“确认并提交这一次”只放行这一条请求，后续提交仍须单独确认。助手保持在业务弹窗上方，确认和停止按钮可点击。

任务期间，手动触发的写请求也进入同一确认门槛；已有权限、幂等、版本、审批及业务校验仍生效。任务结束后，旧文档仍阻断旧表单的延迟提交。成功后可以直接开始另一项受保护网页任务；手动提交前需要“手动接管（刷新当前页）”，停止/失败后开始新任务也须刷新。刷新会清除尚未提交的表单，普通点击和导航不能解除旧任务写入阻断。

## 六角色

| 角色 | 适用示例 |
|---|---|
| 总部管理员 | 经营看板、训练监督、排课与跨店授权数据 |
| 店长 | 本店训练监督、潜客、经营与交班 |
| 前台 | 本店会员、周课表、预约接待与交班 |
| 教练 | 本人课程、学员与训练计划 |
| 会籍顾问 | 本人负责且本店的潜客、体验、续费回访 |
| 会员 | 本人课程、预约、训练及消息 |

路由准入复用现有 accessControl.mjs 和 router 元数据；后台单步规划及每步/确认前身份复核继续按真实角色、门店及登录会话授权。会员不能进入员工训练管理页，而是在会员中心点击“我的训练”。

## 执行与边界

- 浏览器内单例任务引擎读取当前 document、调用既有后端规划接口、使用当前 Vue router 导航和原生 DOM 事件操作，不依赖本机 Edge 控制程序。
- 每次观察生成短期控件引用，动作前核对连接、可见、名称、类型和路由。旧引用、外部链接、新窗口链接、下载链接、密码/隐藏/文件输入、账号切换及整个助手均不成为可执行目标。模型不能点击自己的确认按钮，也不能执行脚本、Shell 或自行编造业务 API。
- 请求边界冻结完整 JSON 和查询参数；多个并发写请求不能共享一次确认。停止、身份变更、页面变化会阻止放行；已发出的请求无法撤回，回执不确定须人工核对，不自动重试或刷新重放。
- 同标签页最多一个任务，最多30步、总计10分钟，等待确认/补充/暂停最长5分钟。步骤间隔默认至少7秒；无效模型规划最多重新观察两次。活动任务每2秒核对服务端身份；初始身份请求挂起时关闭助手也不能稍后启动任务。
- 只有实际页面操作才能产生完成结果；请求保存必须取得真实成功回执。空列表允许作为真实查询结果，不能把模型口头答复当作成功。
- 用户提供的手机号、邮箱、证件号先转换为任务内资料引用，填写时本地还原；后台既有脱敏继续生效。密钥仅保存在后台受保护配置中。
- 当前能力以页面 DOM 为输入，不含屏幕视觉理解、任意 Windows 软件控制或任意复杂网页的可靠自动化。复杂或未支持控件可能需要补充或人工接管。

## 可选文件能力

start.bat 仍会尝试启动本机 127.0.0.1:5188 文件服务。只有生成课表 CSV、请求系统打开成果时使用桥接；普通网页任务不依赖它，不另开 Edge。静态部署或手机 LAN 不接入电脑文件服务，相关文件请求会明确失败，不能假报生成成功。此轮只做桌面验收，不宣称手机实测。

成果默认在桌面 FitChain任务成果，只创建新文件、保留 BOM、转义 CSV 公式并显示字节数和 SHA-256。相同任务及日期不重复生成，同任务同成果不重复打开。打开仍为系统记事本的启动回执“已请求 Windows 打开文件”，不冒称验证了文件窗口。

文件能力只接受私有随机桥接凭证、回环来源和固定工程源；绑定账号、角色、门店、登录会话及任务。副作用前检查会话及请求断连；暂停会取消本次文件请求。已经开始的系统操作不能撤回。会员课表仍是本人服务门店的未来可预约课程，不是历史预约清单。
