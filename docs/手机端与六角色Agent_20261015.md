## 如何体验

1. 电脑照常双击根目录 `start.bat`，访问 `http://localhost:5173/login`。
2. 手机访问时，双击 `start-mobile.bat`。它复用本地后端，再启动手机入口 5174；手机和电脑连接同一可信局域网，使用窗口显示的电脑局域网地址。不要选代理或虚拟网卡的地址。桌面也可访问 `http://localhost:5174/login`。
3. 手机底部有角色主页、常用功能、业务助手和更多菜单。助手包含「会话」「业务工具」「执行记录」；桌面仍使用右下角助手入口。
4. 在业务工具中先查询编号、版本和接待顾问，填写表单生成预览，到执行记录核对对象、时间和动作后确认。确认卡有效期 10 分钟；取消、过期、会话/角色/门店变化后应重新生成。

本机启动测试时，Wi-Fi/以太网地址为 `192.168.1.71`，可尝试 `http://192.168.1.71:5174/login`；地址会随网络变化，以启动窗口为准。脚本不会修改防火墙、证书或后端公网绑定。

## 六角色能力

| 角色 | 真实数据查询 | 首批可确认操作 |
|---|---|---|
| 总部 | 跨店经营、课程、会员、预约、潜客、回访、交班、训练计划 | 课程预约/取消、体验安排 |
| 店长 | 本店经营、课程、会员、预约、潜客、回访、交班、训练计划 | 课程预约/取消、体验安排 |
| 前台 | 本店课程、会员、预约、交班 | 课程预约/取消 |
| 会籍顾问 | 本人且本店的潜客、续费回访、接待顾问及可见课程 | 独立体验安排 |

## 手机与 PWA 边界

同一个 Vue 工程复用登录与业务接口。新增手机底部导航、更多菜单、触控表单、表格容器及全屏助手，保留桌面布局；处理视觉视口变化和 reduced-motion。

生产构建包含 manifest、192/512 图标、安装说明和 Service Worker。缓存只包含公开离线页、manifest 与图标；认证 API、私人页面和业务 HTML 不缓存，离线不显示旧业务资料、不排队写入、不恢复后自动提交。开发服务保持联网使用。

局域网 HTTP 可使用在线 H5。PWA 安装推广需要 HTTPS 或 localhost/回环环境，平台入口各异，参见 [MDN 安装条件](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)。本轮没有配置生产 HTTPS 或操作用户手机；物理手机键盘、系统安装和真机兼容性仍待实际设备验收，不能把浏览器模拟称为真机通过。

## 安全与数据

- `/api/v1/agent` 使用原 `ASSISTANT_USE` 认证，服务器决定工具和参数白名单；会员不可指定其他会员，顾问不可越过本人且本店范围，教练不可操作无关系学员。
- V23 新增 `agent_action`；只保存哈希会话标识。确认请求只接受操作 ID 和 `{}`，不能换参；绑定本人、角色、当前认证门店和登录会话。
- 确认行锁保证重复/并发确认只提交一次；保存回执供重放。执行事务失败先回滚，再单独记录 FAILED，保留实际审计。
- 预约/取消确认按业务顺序锁定并刷新目标，比较预览时的业务快照。调课、取消后复用同 ID 的新预约不会被旧确认卡误操作；潜客操作仍使用领域版本。
- 模型上下文进一步删除私人姓名、手机号、证件、邮箱、完整自由备注与事件文本；保留所需业务编号、状态和时间，限制列表和上下文长度。身份、提示词、历史或备注均不能授予权限。

## 2026-10-15 手机登录403修复

用户真机已能打开登录页，登录时却显示“当前账号没有执行此操作的权限”。实测来源localhost请求到达接口，而局域网Origin被后端限制拦截，原响应是`Invalid CORS request`；前端把这类403误当账号权限不足。修复Vite本地代理：仅当浏览器Origin与接收请求的协议、Host及端口一致时，改写为上游Origin；外来、不同端口及null来源保持原拒绝。后端CORS和账号权限均未更改。前端对应提示也改为来源校验说明。

最终前端207/207及构建通过。真实浏览器从192.168.1.71:5174发起空字段登录请求，现返回正常字段校验（400/1001），不再是CORS403；localhost回归正常，外来来源仍403。未使用或改写真实账号密码，实际账号登录仍需用户刷新手机页面后确认。证据`docs/qa/mobile-agent-20261015/lan-login-verification.json`。本轮没有改防火墙或更新服务器。
