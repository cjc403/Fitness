# 退款、对账与报表使用说明

## 前台、店长和总部

在“会籍与商业中心”的权益行点击“退款”，系统先向服务端取得该权益的报价。不要手工填写退款金额：已核对权益显示服务端报价；未核对权益显示“待核对”，不能猜测为零或原价。

有 `VALUE_RECONCILE` 权限的人员可在报价窗口填写核对原因、剩余次数、逐笔来源订单的未使用金额，以及需要时的历史商品类型、剩余单位、服务起始日和转卡依据。所有金额和来源均应来自订单/凭证；保存后以服务端返回的新报价为准。已核对转卡仅填写本次受领核实原因和可核验依据，不重新核算余额。

填写退款原因后提交申请。若网络超时，请直接重试同一弹窗；同一次申请会保留同一幂等键。取消并明确开始一笔新的申请时才会生成新键。待审批退款会冻结相关权益，冻结、续费、转卡等受阻原因以服务端报价为准。

有审核权限的人员必须填写批准或拒绝原因。申请人自己的待审单不显示自审按钮；服务端仍会再次验证权限和隔离范围。撤回同样要求理由。已审批退款可由有支付登记权限的人员登记：这只记录已经在线下完成的退款，**不会发起真实打款**。请填写渠道、外部凭证、实际完成时间、金额和说明；已登记支付的退款不提供第二次登记。

## 财务报表

有 `FINANCE_REPORT_READ` 权限时，在商业中心的“财务对账报表”选择日期范围。报表展示收款、退款、净现金、已核对余额、待核对权益数、服务消耗、渠道分布与完整性差异。服务消耗中标注的“只读预估”仅用于报表，不会自动补账或修复数据。

`ORDER_PAYMENTS`、`FUNDING_ACCOUNT`、`PAID_REFUND` 等差异需要按提示回到凭证和账务流程核对；报表页面不会执行刷新、修复或退款写入。下载 CSV 时若服务端返回业务错误，页面会显示错误而不会下载空文件。

## 会员和教练

会员在“我的退款”仅能看见自己的退款单号、权益编号、状态、服务端金额及申请/审核/登记支付时间；页面没有退款申请按钮，也不会通过 URL 接收会员 ID。教练没有财务入口。
