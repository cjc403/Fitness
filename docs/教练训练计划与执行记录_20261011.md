# 教练训练计划与执行记录（第4项）

2026-10-11，本地开发。**已完成验收并启用本地V22**；线上没有更新。本模块训练登记与原有私教签到、签课、扣次分开处理。

## 入口与角色

- 教练：左侧“训练计划”，或教练工作台学员行的“训练计划”。
- 店长：左侧“训练计划”，查看本店服务计划，可带原因归档旧计划。
- 总部：左侧“训练计划”，可选择服务门店查看，可带原因归档旧计划。
- 会员：会员主页“我的训练”，只显示自己的已发布或归档计划，可反馈训练感受。
- 前台、会籍顾问没有此模块入口或数据权限。

## 教练操作

1. 点“创建计划”，搜索学员。候选包括本店专属学员，以及本店本人近90天或未来排课上的已预约/签到学员；取消、候补、请假、爽约不会赋予权限。跨店会员必须有符合条件的本店课程关系。
2. 填写标题、目标和计划周期，添加动作。力量动作填写目标组数、次数及可选重量；时长动作填写目标分钟。先保存草稿，草稿不向会员显示。
3. 核对后发布。每会员在同一服务门店最多一个执行中的计划，发布新计划前明确归档旧计划。已发布内容固定，需要变更时归档并创建新计划。
4. 在执行中计划的详情里登记训练，按动作记录实际完成或跳过及原因。训练日期必须在计划周期内且不能在未来，可选择当天本人已签到的对应预约，也可记录独立训练。
5. 通过详情查看历史、目标与实际、会员反馈及操作记录。登记错误时作废并填写原因，原内容继续保留；在执行中的计划里重新登记正确记录。归档计划可查看历史，也可作废错误记录，但不能新增训练。

登记训练不会自动签到、签课、扣课或结算提成。仍需按原私教业务流程完成这些操作。

## 会员操作

在“我的训练”查看计划、动作和每次训练情况；对本人有效训练记录填写1–5分感受和可选反馈，已提交反馈可以修正。作废训练仍保留历史，但不计训练次数且不能继续反馈。草稿与员工审计对会员不可见。会员停用或进入黑名单后不能提交新反馈。店长或总部仍可带原因归档可访问的旧计划，避免失去教练归属后一直占用有效计划名额。

## 数据与故障处理

- 同一意图重复点击或网络重试不会重复登记；改动内容视为新的请求。
- 版本冲突时先重新加载最新内容，再重新确认操作，不自动覆盖他人的变更。
- 页面加载失败会给出错误与重试入口；历史分页显示总数量，操作记录最多展示最近100条。
- 用户切换、门店切换和离开页面后会清理当前资料，过期响应不会跨学员更新界面。
- V22只新增训练模块表，不回填或改写历史财务、私教、预约或体测记录。
