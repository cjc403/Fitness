# 业务问答：营收与追问修复

已在本地启用，入口 http://localhost:5173/login。按 Ctrl+F5 刷新后，在助手的「会话 → 业务问答」验收。本轮没有更新服务器，没有新增付费模型测试。

## 修复内容

- 营收直接回答真实金额、起止日期、统计口径、来源与查询时间，不再用通用提示替代数字。数值只能来自权限内真实查询，不接受聊天历史中声称的金额。
- 未说明时间范围时询问开始日期与结束日期；可接着只回复日期、本月、本周或最近1至93天。只有开始日期不会擅自当作单日查询。经营概况首次默认最近30天，并明确展示范围。
- 服务器保留最近查询条件，用随机上下文编号关联本人、角色、门店及登录会话；追问金额时重新读取业务数据。浏览器不提交查询结果或金额作为可信依据。
- 常见营收查询和金额追问直接执行只读工具，不消耗模型调用。其他模型问答可通过结构化澄清工具询问缺少的真实业务字段，业务校验失败也会显示具体原因；模型文字仍不能冒充写入成功回执。
- 每轮结果卡保留在对应回复下，下一次追问或查询失败不会清空旧卡；补齐经营指标中文标签。
- 总部/店长沿用原经营权限，其他四角色不能越权查询营收。店长本店、总部全部门店的原统计范围保留；不支持的指定单店过滤不会偷偷返回全范围金额。

营收沿用经营分析原接口口径：区间内销售订单登记的实付金额合计，**不是扣除退款后的净收款**。没有改变记账、订单或日结规则。
