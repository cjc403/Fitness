# 潜客与体验课操作说明

本轮实现用户批准的第2项功能，采用用户选择的**独立体验预约**。运行与验证结果见文末。本轮只在本地开发，发布服务器需要用户另行明确要求。

## 入口与可见范围

登录后，左侧点击**潜客与体验课**（`/leads`）。会籍顾问看本人且属于本店的潜客；店长看本店；总部管理员可查看全部门店并按门店筛选。前台、教练、会员端不开放潜客资料。

## 日常使用

1. **新建潜客**：填写姓名、大陆手机号、咨询来源、意向和负责顾问，可约定下次联系时间。只建立咨询档案，不创建会员、账号、订单或权益。手机号在同一门店不可重复；手机号、来源和门店建档后固定，防止渠道归因被改写。
2. **记录跟进**：记录电话、微信、到店等沟通，选择已联系、未联系上、已到店、有意向或已流失。每次记录追加保存；下次联系时间用于今日/逾期任务。已流失潜客可选择重新跟进，已开卡潜客进入会员运营流程。
3. **安排体验**：选择接待顾问、未来的起止时间与体验内容。时长15—180分钟，同一顾问的预约不能重叠，同一潜客最多一个待处理预约。
4. **登记结果**：从档案中的预约选择已体验、未到店或已取消，并写明情况。已体验/未到店只能在预约开始后登记。取消后可以重新预约，旧记录保留。
5. **办理开卡**：先处理待体验预约，然后选择直接开卡或关联合格订单。顾客可以直接办理开卡，不强制先体验。

阶段随实际动作变化：咨询中 → 已到店 → 待体验 → 已体验 → 已开卡；也可标记已流失、重新跟进。取消预约后恢复至已有事实对应的阶段。

## 两种转化方式

**创建会员并记账开卡**：确认已实际收到款项后，选择本店在售产品、微信/支付宝/银行卡/现金渠道与实收金额。服务复用现有开卡流程，生成会员、订单、权益及相关记账记录；没有接入新的支付网关。会员编号为`LEAD-{潜客ID}`，登录账号仍由已有会员账号开通流程办理。任何步骤失败都会回滚，避免留下半成品会员或重复权益。

**关联已办理订单**：适用于前台已经建会员并开卡的情况。系统只提供同门店、同手机号、会员建档和付款时间均不早于潜客建档的有效新开卡订单；顾问办理时还要求会员归属顾问一致，店长/总部可在本身可见范围内核验关联。净实收须大于零，一个订单只归因一次。关联保留原会员资料与账号，不再新建订单。

既有会员没有合格新开卡订单时，继续通过会员档案或续费回访处理；不将历史订单、续费订单或无效付款冒充获客转化。

## 看板与安全保护

- 今日联系、逾期联系、今日体验、阶段与关键字筛选；列表分页。
- 各咨询渠道显示潜客总数、到店人数、体验完成人数、有效开卡人数和转化率。分母使用当前门店/顾问可见范围内的潜客总数；列表筛选与翻页不改变渠道统计。
- 已开卡记录保留历史；订单全额退款后不再计入有效开卡转化，部分退款按剩余净实收判断。
- 连点和同内容网络重试不会重复保存或开卡。其他人修改过档案时，会提示重新加载，避免覆盖他人的工作。
- 门店负责人可以更换负责顾问；顾问不能自行把其他人的潜客归给自己。

独立体验由接待顾问协调实际活动，本轮不预留团课名额、教室或教练资源，不扣会员课时，也不改变原团课/候补/私教流程。
