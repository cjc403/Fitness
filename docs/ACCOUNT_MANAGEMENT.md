# 员工账号与会员账号闭环

## 账号开通规则

- 总部管理员可以创建总部管理员、店长、教练和前台账号，并分配所属场馆。
- 店长只能创建和管理本门店的教练、前台账号。
- 教练、前台不能创建员工账号，也不能修改自己的角色。
- 会员可以从登录页公开注册，也可以先由前台建立会员档案，再点击“开通账号”。
- 所有角色均由后端账号决定，登录页面不能自行选择或改变角色。

## 临时密码流程

后台创建员工账号、为会员开通账号或重置密码后，账号会被标记为“待首次修改”。用户可以登录，但除修改密码和退出外，其他接口都会返回 `1105`。密码修改成功后才能进入对应工作台。

密码至少 8 位，并且必须同时包含：

- 大写字母
- 小写字母
- 数字
- 特殊字符

密码仅以 BCrypt 哈希形式存入数据库，接口不会返回明文密码。

## 页面入口

- 登录页 `/login`：所有角色统一登录。
- 会员注册 `/register`：公开注册会员账号并自动建立会员档案。
- 首次改密 `/change-password`：临时密码用户的强制入口。
- 员工账号 `/accounts`：总部或店长创建、编辑、启停员工及重置密码。
- 会员管理 `/members`：查看会员账号状态、开通账号、重置密码及启停账号。

## 角色工作台

| 角色 | 登录后的默认页面 |
| --- | --- |
| 总部管理员 | 经营看板 |
| 店长 | 本店经营看板 |
| 教练 | 教练工作台 |
| 前台 | 会员管理 |
| 会员 | 会员中心 |

正式环境不自动植入弱口令演示账号。账号应通过管理页面或会员注册页面创建，并在首次登录时修改临时密码。
