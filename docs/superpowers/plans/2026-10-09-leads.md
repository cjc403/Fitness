# 潜客与独立体验预约 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Backend and frontend consume the fixed API contract and can be implemented independently, with separate reviews.

**Goal:** 实现已批准的第2项潜客运营闭环，并验证本地可用。
**Architecture:** 独立lead模块、追加事件日志、独立预约；事务复用已有CommercialService；新增权限和V20迁移。Vue页保持当前主题，捕获请求意图并隔离异步生命周期。
**Tech Stack:** Java17/Spring Boot3/JPA/Flyway/PostgreSQL，Vue3/TypeScript/Element Plus，JUnit/MockMvc与node:test。
**Spec:** `docs/superpowers/specs/2026-10-09-leads-design.md`（包含准确字段与端点）。

## Global Constraints

- 本轮仅本地，不提交/推送/部署；保留已有全部未提交改动。用户已明确开始第2项开发，并选择独立预约，按此授权持续推进。
- 使用当前共享工作区；新worktree不包含既有未提交功能，故不切换工作区。构建在临时后端快照，避免覆盖运行JAR；测试业务数据在隔离库。
- 不改已有迁移，不覆盖会员/账号/密码，不输出配置秘密。交接文档在仓库外。
- DTO契约若需要修改，先同步spec与前端实现者；控制台和前端不得显示实现细节/SQL。

## Review Focus

1. 同门店其他顾问、跨门店及旧账号响应泄漏 → backend isolation + frontend session race tests。
2. 同键在时间过期/版本变化后重放、异键并发 → integration replay/concurrency tests；frontend retry/capture tests。
3. 预约时间重叠、单人重复预约、取消/未到店的阶段恢复 → trial integration tests。
4. 转化事务中途失败、历史订单伪归因、重复订单归因 → conversion rollback/link tests。
5. 全额/部分退款导致转化统计虚高与筛选改变分母 → channel stats tests。
