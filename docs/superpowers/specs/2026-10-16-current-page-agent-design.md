# 当前网页 Agent 修正设计

用户明确：在当前正在看的 FitChain 标签页中观察、点击、填写、切换页面；不得用另一个浏览器的完成状态代替当前页实际操作。沿用此前授权，直接实施推荐方案，仅本地开发。

## 执行面

- Vue 内的单例任务引擎驱动当前 document 和 router；默认会话模式为“网页执行”，任务页为“网页任务”。导航不刷新文档，保留助手及任务；六角色复用现有路由权限元数据和后端身份校验。
- 每步先读取最新可见控件和当前值，生成短期引用，再请求现有后端单步规划。只接受允许动作，不接受脚本、选择器或外部地址。排除整个助手、账号/门店切换及口令控件。控件变化或手动导航使旧步骤失效，重新观察。
- 当前页描边展示操作目标；任务步骤记录真实路由与控件结果，不伪造截图。暂停/停止/身份变更立即阻止后续动作；关闭面板暂停，不关闭用户标签页。刷新网页终止内存任务。

## 提交边界

- 当前页任务活动期间，统一 Axios 边界跟踪业务请求。除明确只读工具外，所有写请求先冻结实际参数，逐次人工确认；这也涵盖任务期间手动触发的提交，页面明确提示。已有权限、审批、幂等和业务校验仍执行。
- 请求在确认前不出网；确认后核对身份、原页面和参数，单次放行，不刷新重放写请求。停止拒绝挂起请求。结果不确定时停止并要求人工核对。
- 多个写请求同时触发时拒绝额外提交，不能一次确认放行多个请求。模型不能点击助手内的确认按钮。
- 终止后的文档不得通过普通可信交互解锁旧异步提交。手动接管明确刷新当前标签页（提示未提交表单会清除）；成功后可直接开启另一项受保护网页任务，失败/停止后须先刷新。初始创建异步身份请求也受调用方取消和生命周期世代约束。

## 文件

网页操作不依赖本机执行器；已有本机桥接改为可选文件能力，在受保护目录生成/请求打开本任务课表文件，无需启动另一个 Edge。未连接时明确提示，不假报成果。

## 验收

桌面：同一个 Playwright Page 从经营看板到训练计划，地址与正文变化且页数不增加；六角色实际任务；可见表单填入和自定义下拉；隔离库确认前0/确认后1与重复确认拒绝；暂停、停止、身份变更、助手排除、外链拒绝。正常本地只读验收；不写真实业务数据、不更新服务器。
