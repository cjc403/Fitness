# 六角色网页 Agent：对象定位与执行反馈升级

用户要求：查明同一 DeepSeek 接口在本项目执行能力差的原因，修复“流瑜伽改价99”却反复编辑其他课程的问题，提升六角色项目内任务的可靠性。采用已授权的推荐方案直接开发；仅本地、桌面，保留当前标签页和原有人工确认、权限、请求冻结、停止及旧回调阻断。

## 已确认缺陷

- 控件快照只提供平铺按钮文字，多个“编辑课程”没有课程或行上下文。
- 弹窗打开后背景按钮仍在控件候选集中，执行器也可点击它们。
- 读取主页面正文优先，弹窗可能被6000字符预算截断；数字 spinbutton 当前值没有进入字段状态。
- 反馈多为“已点击”，没有结构化核对操作后的弹窗、字段和对象；循环只受30步总上限限制。

## 方案

复用现有后端工具协议，在共用 DOM driver 和任务引擎修复信息与反馈链。按钮关联最近文章/表格行/列表项的标题和业务上下文；引用绑定上下文，同行对象替换即过期。观察和操作限定最上层业务弹窗及其关联下拉框；当前字段值、选择/禁用状态和弹窗正文优先。目标关联对象优先进入60控件预算，并提供紧凑对象索引。

每步完成后获取真实状态反馈，历史保留动作对象及结果。以无引用序号的状态指纹检测同态重试和来回循环，首先给模型明确恢复信息，再阻止重复动作并请求必要补充；不通过自动提交绕过确认。完成仍要求原先的真实请求回执。无需更改模型、引入任意脚本执行或扩展业务API权限。

## 验收

- 原截图同义命令：只修改指定课程价格至99，其他课程/字段不变；确认前0写、确认后1写、重复确认拒绝。
- 错误课程弹窗恢复、同名按钮/相似课程、超过60控件后的目标、多个字段修改与禁用权限。
- DOM单元夹具覆盖对象变更后的过期引用、最上层弹窗/关联下拉框、数字状态、助手/敏感字段排除。
- 引擎覆盖重复无效动作恢复、循环止损、真实后态反馈、暂停停止不绕过。
- 六角色真实模型消息及各自访问范围回归、前端全量测试与构建、独立审查；只向带显式标记的隔离库试写。

不宣称与其他工具在全部任务上等价，按可复现的项目内任务报告成功、失败和未测范围。
