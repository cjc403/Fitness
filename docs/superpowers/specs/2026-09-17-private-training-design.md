# 私教课包消课与教练结算（用户已在对话中批准）

保留 Java 17 / Spring Boot 3.3.13 / Vue 3 / PostgreSQL 架构及所有历史数据，不追溯扣课。

## 流程与约束
- 新私教预约绑定本人的本店有效 PRIVATE_PACKAGE。预约预占一节；remainingUses 保持未消费余额，reservedUses 单独记录，availableUses=remainingUses-reservedUses。有效期需覆盖开课日期。
- 候补不占课次，递补时重新校验课包；不能递补的记录留下取消原因。预约写入的锁顺序为门店→排课→教练（必要时）→权益。PostgreSQL门店序列化锁采用FOR NO KEY UPDATE，与外键KEY SHARE检查兼容；权益变更锁后重新读取。
- 签到仅表示到课。课程结束后，本人教练提交授课，进入 PENDING；本人会员签课后变为 CONFIRMED，同时扣一节并生成不可变的金额与提成快照。
- 自助取消/请假截止开课前两小时。爽约记录积分并释放占用，不自动消费；临时后台取消仅总部/店长可操作且必须给原因，前台不能绕过。
- 存在预占、待签课时禁止冻结、转卡、退款；已消费的私教课包禁止通过普通退款恢复，已结算消课禁止直接撤销。店长/总部可对未结算签课作带原因的冲正，保留审计记录。
- 私教课包存储成交单价快照；续费使单价按未消费余额与新购课次加权，历史已确认消课不改变。消课时锁定提成比例和金额。
- 提成按门店+教练配置（0至100%）。未配置默认40%，页面明确标记。月结单按门店+教练+月份唯一，DRAFT→APPROVED；只有总部和本店店长可生成/审核。生成或更新草稿绑定同月未结算消课，首次无记录时拒绝。当前月可更新草稿、次月才能审核；审核前自动补齐，实际确认月份决定归属，迟签不追溯旧月。锁定教练行串行化确认、月结和冲正。审核人不能是结算对象。
- 会员只看本人，教练只看本人，前台只看本店记录，店长仅本店，总部跨店。未开通本模块的历史预约标为历史未关联，不自动扣课或计入新结算。

## 发布验收
先完整本地测试/构建，再备份服务器数据库和旧前后端。新增 V8 Flyway 迁移，不修改 V1-V7；在临时 PostgreSQL 数据库验证迁移和流程。上传同一构建产物，替换服务、切换前端、验证健康及五角色登录。失败恢复旧产物，不删除新增兼容表。不得输出密码、JWT 或 API Key。
